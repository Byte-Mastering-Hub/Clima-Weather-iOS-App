# 🌤️ Clima - Weather App

Clima is a simple weather application built with **Swift and UIKit**.  
It uses the **OpenWeatherMap API** to fetch real-time weather data based on the user's location or searched city.

## ✨ Features

- 📍 Current location weather
- 🔍 Search weather by city
- 🌡️ Real-time temperature
- 🌤️ Dynamic weather conditions
- ☁️ Weather icons
- 🌎 Location-based weather updates
- 🔄 API-based weather data

## 🛠️ Built With

- Swift
- UIKit
- MVC Architecture
- OpenWeatherMap API
- Core Location
- Xcode

## 🏗️ Architecture

The application follows the **MVC (Model-View-Controller)** architecture:

- **Model** — Handles weather data and API response models.
- **View** — Displays weather information and UI.
- **Controller** — Handles user interaction, API requests, and updates the UI.

## 🌐 API

Weather data is provided by **OpenWeatherMap API**.

> ⚠️ Do not commit your OpenWeatherMap API key directly to GitHub.
> Store sensitive API keys securely or use a configuration file that is excluded from Git.
